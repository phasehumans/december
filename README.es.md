December es un (so much) better agente de programación para terminal y nube. Comprende tu base de código y te ayuda a desarrollar más rápido escribiendo código, corrigiendo errores y ejecutando comandos. Úsalo directamente en tu terminal o junto con tu IDE favorito.

**También disponible en la web en <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

<p align="center">
  <img src="https://github.com/user-attachments/assets/585e6ff5-0403-45f5-89c3-c2d3d168962c" alt="December" width="80%"/>
</p>

- **Escribe código y ejecuta comandos:** Pídele que cree funciones, corrija errores o ejecute pruebas. Él hace el trabajo por ti.
- **Traspaso a la nube:** Usa _/handoff_ para continuar tu sesión en **<a href="https://trydecember.com" target="_blank">trydecember.com</a>**.
- **Trae tu propia IA:** Usa claves de API para OpenAI, Anthropic, Gemini y más de 150 proveedores, o inicia sesión a través de December para usar créditos de December.

### Primeros pasos

1. Instala December:

```bash
npm install -g @trydecember/cli
```

2. Ve al directorio de tu proyecto y ejecuta `december`.
