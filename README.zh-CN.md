December 是一个面向终端与云端的 (so much) better 编程智能体。它能够理解你的代码库，并通过编写代码、修复 Bug 和运行命令来帮助你更快速地构建项目。你可以直接在终端中使用它，或者配合你喜爱的 IDE 一起使用。

**也可在网页端使用：<a href="https://trydecember.com" target="_blank">trydecember.com</a>**

  <img src="https://github.com/user-attachments/assets/585e6ff5-0403-45f5-89c3-c2d3d168962c" alt="December" width="80%"/>
</p>

- **编写代码与运行命令：** 让它构建新功能、修复 Bug 或运行测试，它会替你完成这些工作。
- **云端接力：** 使用 _/handoff_ 命令在 **<a href="https://trydecember.com" target="_blank">trydecember.com</a>** 上继续你的会话。
- **自带 AI 模型：** 支持 OpenAI、Anthropic、Gemini 以及其他 150+ 种模型的 API 密钥，也可以通过 December 登录直接使用 December 额度。

### 快速上手

1. 安装 December：

```bash
curl -fsSL https://trydecember.com/install.sh | bash
```

2. 进入你的项目目录并运行 `december`。
