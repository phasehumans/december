December 是一个更好的编程智能体。它读取你的代码、编写修改并运行命令，可以在终端中使用，也可以在云端 [trydecember.com](https://trydecember.com) 使用。

<p align="center">
  <img src="https://github.com/user-attachments/assets/8e15b973-eddc-4bcb-96a0-26d37c35c718" alt="December" width="100%"/>
</p>

- 支持任意模型。可以关联你已付费的套餐（Claude、ChatGPT、GitHub Copilot 或 Gemini），登录 December 账号，或使用来自 40 多家服务商的 API 密钥。
- 在云端运行。December Cloud 在沙箱中运行你的项目，并提供应用的实时预览。
- 拆分大任务。December 可以把子任务交给多个辅助智能体同时处理。
- 扩展工具。用 Skills 教会 December 你的工作流程，并通过 MCP 连接外部工具。

### 快速上手

1. 安装 CLI：

```bash
npm install -g @trydecember/cli
```

2. 进入你的项目目录并运行 `december`。

3. 输入 `/login` 连接一个模型，然后告诉 December 要做什么。

更多内容请阅读[文档](https://trydecember.com/docs)。
