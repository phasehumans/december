December 是一个 (so much) better 编程智能体。它通过编写代码、修复 Bug 和运行命令来帮助你更快速地构建项目。你可以直接在终端中使用它，或者配合你喜爱的 IDE 一起使用。

**也可在网页端使用：<a href="https://trydecember.com" target="_blank">trydecember.com</a>**

- **编写代码与运行命令：** 让它构建新功能、修复 Bug 或运行测试，它会替你完成这些工作。
- **自带 AI 模型：** 支持 OpenAI、Anthropic、Gemini 以及其他 100+ 种模型的 API 密钥，也可以通过 December 登录直接使用 December 额度。

### 快速上手

1. 安装 December：

Bash (macOS 与 Linux)：

```bash
curl -fsSL https://trydecember.com/install.sh | bash
```

PowerShell (Windows)：

```powershell
irm https://trydecember.com/install.ps1 | iex
```

NPM：

```bash
npm install -g @trydecember/cli
```

2. 进入你的项目目录并运行 `december`。
