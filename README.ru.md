December является более совершенным агентом для программирования. Он читает ваш код, вносит изменения и выполняет команды в терминале или в облаке на [trydecember.com](https://trydecember.com).

<p align="center">
  <img src="https://github.com/user-attachments/assets/8e15b973-eddc-4bcb-96a0-26d37c35c718" alt="December" width="100%"/>
</p>

- Любая модель. Подключите подписку, за которую вы уже платите (Claude, ChatGPT, GitHub Copilot или Gemini), войдите в аккаунт December или используйте свои API-ключи от более чем 40 провайдеров.
- Работа в облаке. December Cloud запускает ваш проект в песочнице с живым предпросмотром приложения.
- Разделение больших задач. December может передать подзадачи вспомогательным агентам, которые работают одновременно.
- Новые инструменты. Научите December своим процессам с помощью скиллов и подключайте инструменты через MCP.

### Начало работы

1. Установите CLI:

```bash
npm install -g @trydecember/cli
```

2. Перейдите в каталог вашего проекта и запустите `december`.

3. Введите `/login`, чтобы подключить модель. Затем скажите December, что сделать.

Подробнее читайте в [документации](https://trydecember.com/docs).
