December - это (so much) better агент для написания кода. Он помогает быстрее разрабатывать проекты: пишет код, исправляет ошибки и выполняет команды. Используйте его прямо в терминале или вместе с вашей любимой IDE.

**Также доступно в веб-версии на <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

  <img src="https://github.com/user-attachments/assets/8e15b973-eddc-4bcb-96a0-26d37c35c718" alt="December" width="100%"/>
</p>

- **Написание кода и запуск команд:** поручайте создание новых функций, исправление ошибок или запуск тестов - агент выполнит работу за вас.
- **Облачные песочницы:** развертывайте удаленные среды выполнения и интерактивные превью.
- **Подключение своего ИИ:** используйте API-ключи OpenAI, Anthropic, Gemini и более 100 других провайдеров или войдите через December для использования кредитов December.
- **Постоянная память рабочего пространства:** запоминает правила проекта и стандарты команды между сессиями без деградации контекста.
- **Автономные мультиагентные команды:** параллельно запускает фоновых субагентов для анализа документации, отладки и прогона тестов.
- **Расширяемые Skills и MCP:** подключайте собственные кастомные навыки (skills) и интегрируйтесь с внешними инструментами разработки или API через MCP.

### Начало работы

1. Установите December:

```bash
npm install -g @trydecember/cli
```

2. Перейдите в каталог вашего проекта и запустите `december`.
