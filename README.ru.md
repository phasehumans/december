December - это (so much) better агент для написания кода для терминала и облака. Он понимает вашу кодовую базу и помогает быстрее разрабатывать проекты: пишет код, исправляет ошибки и выполняет команды. Используйте его прямо в терминале или вместе с вашей любимой IDE.

**Также доступно в веб-версии на <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

  <img src="https://github.com/user-attachments/assets/585e6ff5-0403-45f5-89c3-c2d3d168962c" alt="December" width="80%"/>

- **Написание кода и запуск команд:** поручайте создание новых функций, исправление ошибок или запуск тестов - агент выполнит работу за вас.
- **Синхронизация с облаком:** используйте команду _/handoff_, чтобы продолжить сессию на **<a href="https://trydecember.com" target="_blank">trydecember.com</a>**.
- **Подключение своего ИИ:** используйте API-ключи OpenAI, Anthropic, Gemini и более 150 других провайдеров или войдите через December для использования кредитов December.

### Начало работы

1. Установите December:

```bash
npm install -g @trydecember/cli
```

2. Перейдите в каталог вашего проекта и запустите `december`.
