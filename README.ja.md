December はターミナルとクラウドに対応した (so much) better なコーディングエージェントです。コードベースを理解し、コードの作成、バグ修正、コマンドの実行を通じて、開発をより迅速に進めるサポートをします。ターミナルで直接利用することも、お気に入りの IDE と併用することも可能です。

**ウェブ版も利用可能: <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

  <img src="https://github.com/user-attachments/assets/585e6ff5-0403-45f5-89c3-c2d3d168962c" alt="December" width="80%"/>
</p>

- **コード作成とコマンド実行:** 新機能の実装、バグ修正、テストの実行を指示すれば、自動で作業を行います。
- **クラウドハンドオフ:** _/handoff_ コマンドを使用することで、**<a href="https://trydecember.com" target="_blank">trydecember.com</a>** 上でセッションを継続できます。
- **お好みの AI を持ち込み:** OpenAI、Anthropic、Gemini、その他 150 以上のモデルの API キーを使用するか、December にログインして December クレジットを利用できます。

### クイックスタート

1. December をインストール:

```bash
npm install -g @trydecember/cli
```

2. プロジェクトのディレクトリに移動して `december` を実行します。
