December हा एक (so much) better कोडिंग एजंट आहे. तो कोड लिहून, बग्स दुरुस्त करून आणि कमांड्स चालवून तुम्हाला जलद काम करण्यास मदत करतो. याचा वापर थेट तुमच्या टर्मिनलमध्ये किंवा तुमच्या आवडत्या IDE सोबत करा.

**वेबवर देखील उपलब्ध: <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

- **कोड लिहितो आणि कमांड्स चालवतो:** नवीन फीचर्स तयार करणे, बग्स फिक्स करणे किंवा टेस्ट्स चालवण्यास सांगा. तो हे काम तुमच्यासाठी करतो.
- **क्लाउड सँडबॉक्सेस:** रिमोट वातावरण आणि थेट प्रिव्ह्यू त्वरित सुरू करा.
- **तुमची स्वतःची AI वापरा (BYOK):** OpenAI, Anthropic, Gemini आणि इतर १००+ प्रोव्हायडर्सच्या API की वापरा, किंवा December क्रेडिट्स वापरण्यासाठी December द्वारे लॉगिन करा.
- **पर्सिस्टंट वर्कस्पेस मेमरी:** कॉन्टेक्स्ट खराब न होता विविध सेशन्समध्ये प्रोजेक्टचे नियम आणि टीमच्या पद्धती शिकून घेतो.
- **स्वायत्त मल्टी-एजंट टीम्स:** डॉक्स रिसर्च करणे, डिबगिंग आणि टेस्ट्स चालवण्यासाठी समांतर बॅकग्राउंड सब-एजंट्स चालवतो.
- **विस्तारण्यायोग्य Skills आणि MCP:** सानुकूल स्किल्स जोडा आणि MCP द्वारे बाह्य डेव्हलपर टूल्स किंवा APIs कनेक्ट करा.

### सुरुवात करा

1. December इन्स्टॉल करा:

```bash
npm install -g @trydecember/cli
```

2. तुमच्या प्रोजेक्ट डिरेक्टरीमध्ये जा आणि `december` चालवा.
