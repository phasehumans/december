December हा टर्मिनल आणि क्लाउडसाठीचा एक (so much) better कोडिंग एजंट आहे. तो तुमचा कोडबेस समजून घेतो आणि कोड लिहून, बग्स दुरुस्त करून आणि कमांड्स चालवून तुम्हाला जलद काम करण्यास मदत करतो. याचा वापर थेट तुमच्या टर्मिनलमध्ये किंवा तुमच्या आवडत्या IDE सोबत करा.

**वेबवर देखील उपलब्ध: <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

- **कोड लिहितो आणि कमांड्स चालवतो:** नवीन फीचर्स तयार करणे, बग्स फिक्स करणे किंवा टेस्ट्स चालवण्यास सांगा. तो हे काम तुमच्यासाठी करतो.
- **क्लाउड हँडऑफ (Cloud Handoff):** तुमचे सेशन **<a href="https://trydecember.com" target="_blank">trydecember.com</a>** वर चालू ठेवण्यासाठी _/handoff_ चा वापर करा.
- **तुमची स्वतःची AI वापरा (BYOK):** OpenAI, Anthropic, Gemini आणि इतर १५०+ प्रोव्हायडर्सच्या API की वापरा, किंवा December क्रेडिट्स वापरण्यासाठी December द्वारे लॉगिन करा.

### सुरुवात करा

1. December इन्स्टॉल करा:

```bash
npm install -g @trydecember/cli
```

2. तुमच्या प्रोजेक्ट डिरेक्टरीमध्ये जा आणि `december` चालवा.
