This page helps you connect December to a model. You can link a plan, sign in with December, or use your own keys.

## Three ways to connect

Run `/login` in a session and pick one option:

- Link a plan: Use a Claude, ChatGPT, GitHub Copilot, or Gemini plan that you already pay for.
- Sign in with December: Use your December Cloud account and its credits.
- Use your own keys: Add an API key from a model provider. This is also called bring your own key (BYOK).

## Bring Your Own Key (BYOK)

### Supported Providers

December works with many providers. These are some of them, with the model December uses first:

| Provider      | Default model             |
| :------------ | :------------------------ |
| Anthropic     | `claude-opus-5`           |
| OpenAI        | `gpt-5.6-sol`             |
| Google Gemini | `gemini-3.8-flash`        |
| DeepSeek      | `deepseek-v4-pro`         |
| Groq          | `openai/gpt-oss-120b`     |
| Mistral       | `mistral-large-latest`    |
| OpenRouter    | many open and paid models |

After you add a key, December gets the model list from the provider. Run `/model` to pick a different model.

### Configuring Keys

To save a key from your terminal, run `december key` with the provider name and the key:

```bash
december key anthropic sk-ant-...
```

If you leave out the key, December asks you for it. To send requests through a proxy, add `--base-url <url>`.

December saves your keys in `~/.december/config.json` on your computer. If you use your own keys, the CLI sends requests straight to the provider.

## December credits in December Cloud

December Cloud runs on December credits or on your own keys. A run on your own keys uses no December credits.

### Add credits and get a receipt

Open **Settings > Billing**. The page shows your balance.

- To buy credits, select **Add credits**.
- To use a code, select **Redeem code**.
- To get a receipt, go to **History** and select the link in the **Receipt** column of a payment. December downloads a PDF.

### See your usage

Open **Settings > Usage**. The page shows three totals for the period: **Spent**, **Tokens**, and **Sessions**. A chart shows the spend for each day. Below the chart, a list shows each row of usage with its date, project, model, tokens, and cost.

- Use **Period** to pick 1, 7, 30, or 90 days.
- Use **Paid with** to show runs on credits, runs on your own keys, or all runs.

### Set a spend limit

A spend limit stops December before it uses more credits than you want. Open **Settings > Billing** and go to **Limits**.

| Limit                                  | What it does                                                     |
| :------------------------------------- | :--------------------------------------------------------------- |
| Tell me when the balance is under      | December tells you when your balance goes below this amount.     |
| Pause a session when it reaches        | December pauses a session when the session reaches this amount.  |
| Pause all sessions at a day's total of | December pauses your sessions when your day reaches this amount. |

When a session reaches a limit, December pauses it and asks you, for example "Reached $5. Continue?". Select **Continue** to let the session use the same amount again. Select **Stop here** to end the run.

Runs on your own keys do not count toward a limit.

### Invite a friend

Open **Settings > Billing**. In the **Invite a friend** row, select **Copy link** and send the link to a friend.

Your friend signs up with the link. After the first payment of $10 or more of your friend, December adds the credit to both accounts. The row shows the amount.

## Link a plan from the terminal

To link a plan without opening a session, run `december link` with the provider name:

```bash
december link claude
```

The provider names are `claude`, `chatgpt`, `copilot`, `gemini`, and `amazon-q`.
