## Bring Your Own Key (BYOK)

December is 100% model-agnostic. You can use your own API keys with **zero markup** on token prices:

### Supported Providers

- **Anthropic**: Claude Fable 5.1, Claude Fable 5
- **OpenAI**: GPT 5 series (GPT-5.6 Sol, GPT-5.6 Terra), GPT-6 Astra
- **Google Gemini**: Gemini 3.8 Flash, Gemini 3.8 Pro
- **DeepSeek**: DeepSeek R1, DeepSeek V3
- **OpenRouter**: Access to 100+ open and proprietary models

### Configuring Keys

In your terminal, run:

```bash
december login
```

Select **Configure Custom API Keys (BYOK)** and paste your key. Keys are securely stored in your local configuration directory (`~/.december/config.json`) and never transmitted to December servers when in local mode.
