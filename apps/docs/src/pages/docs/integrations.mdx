## Bring Your Own Key (BYOK)

December is 100% model-agnostic. You can use your own API keys with **zero markup** on token prices:

### Supported Providers

- **Anthropic**: Claude 3.7 Sonnet, Claude 3.5 Sonnet, Claude Opus 5
- **OpenAI**: GPT-4o, o3-mini, GPT-5.6 Sol, o1
- **Google Gemini**: Gemini 2.5 Pro, Gemini 2.5 Flash, Gemini 3.7 Flash
- **DeepSeek**: DeepSeek V3, DeepSeek R1, DeepSeek V4 Pro
- **Groq**: Llama 3.3 70B Versatile, Qwen 3.8 27B
- **Mistral AI**: Codestral Latest, Devstral, Mistral Large
- **OpenRouter**: Access to over 100 open and proprietary models

### Configuring Keys

In your terminal, run:

```bash
december login
```

Select **Configure Custom API Keys (BYOK)** and paste your key. Keys are securely stored in your local configuration directory (`~/.december/config.json`) and never transmitted to December servers when in local mode.
