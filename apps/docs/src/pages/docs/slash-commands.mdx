This page lists the slash commands you can type in a December CLI session. Type `/` in the prompt to see the list. Type `/help` to see the commands and keyboard shortcuts.

## Available Slash Commands

### `/login`

Opens the login menu. Pick one option:

- Link a plan: Use a Claude, ChatGPT, GitHub Copilot, or Gemini plan that you already pay for.
- Sign in with December: Use your December Cloud account and its credits.
- Use your own keys: Add an API key for OpenAI, Anthropic, Gemini, Groq, OpenRouter, DeepSeek, or another provider.

To link a plan directly, add the provider name. For example: `/login claude`.

### `/model`

Opens the model menu. The menu shows the models from the provider you connected. For example:

- Anthropic: `claude-opus-5`, `claude-sonnet-5`, `claude-fable-5-1`
- OpenAI: `gpt-5.6-sol`, `gpt-5.6-terra`
- Google Gemini: `gemini-3.8-flash`, `gemini-2.5-pro`
- DeepSeek: `deepseek-v4-pro`, `deepseek-reasoner`

If you have not connected a model, December tells you to run `/login` first. To change the provider, type `/switch`.

### `/clear`

Clears the conversation history. Your file changes stay. Use it when you start a task that is not related to the last one.

### `/docs`

Opens the December documentation at `trydecember.com/docs` in your browser.

### `/effort`

Sets how much the model reasons before it answers. There are two levels:

- `fast`: Less reasoning, faster answers, and lower token cost. This is the default.
- `deep`: More reasoning for hard design and debugging work.

Type `/effort` to open the menu, or type `/effort deep` to set the level directly. If a model does not support reasoning control, it runs in standard mode.

### `/plugin`

Opens the plugin view. Use it to install, turn on or off, and remove plugins, skills, and MCP servers. It also manages marketplaces. See [Plugins & Marketplaces](/docs/plugins).

In the **Installed** tab, press `f` to show only skills.

To run a skill, type `/` and the skill name: `/<skill-name>`. You can add a task after the name.

### `/memory`

Shows your project `AGENTS.md`. If there is no `AGENTS.md`, it shows `CLAUDE.md`. Press `c` to make a starter `AGENTS.md` when December finds no file.

### `/learn`

Saves a lesson from the conversation, so that later sessions follow it. December writes rules and project facts to `AGENTS.md`. It writes procedures with many steps as a skill in `.december/skills/`.

Type `/learn` to let December find the lesson in the recent conversation. Or type the lesson after the command: `/learn never use axios, use lib/http.ts`. See [Save a lesson with /learn](/docs/memory#save-a-lesson-with-learn).

### `/plan`

Makes a plan before December changes code. You approve, change, or reject the plan.

- Type `/plan <goal>` to plan one task.
- Press `shift+tab` or type `/plan` with no goal to turn plan mode on. In plan mode, each prompt starts a plan. The prompt shows `[plan]`.
- Press `shift+tab` again to turn plan mode off.

### `/compact`

Summarizes the conversation now, so it uses less of the context window. December keeps the last few messages as they are.

To tell December what to keep, add it after the command: `/compact keep the auth refactor details`.

The conversation shows a line where the compaction happened, with the token count before and after. December also compacts on its own when the context window is 80% full. You cannot run `/compact` while December works on a turn.

### `/skills`

Lists your skills, grouped by where they come from: the project, your user folder, plugins, or built-in. The list also shows skills that December could not load, with the error.

- Press `Enter` to read a skill.
- Press `r` or type `/skills reload` to scan the skill folders again.

After a reload, `/skill:<name>` uses the new list at once. The agent gets the new list in the next session. This keeps the prompt cache of the current session.

### `/check`

Checks your setup and shows the problems with a fix for each one. It checks:

- The install, and the API key or login for the active provider.
- The settings, hooks, and keybindings files.
- Your MCP servers, and if they started.
- Skills that December cannot load.
- The size of `AGENTS.md`. December warns if the file is larger than 40,000 characters, because December sends it with every request.

Press `r` to run the checks again. To check from the terminal, run `december doctor`.

### `/permissions`

Manages the allow and deny rules for tools. Press `tab` to switch between the allow rules and the deny rules.

- Allow rules: In always-ask mode, December does not ask before a call that matches an allow rule.
- Deny rules: December blocks each call that matches a deny rule. This applies in every mode, before the other checks.

A rule can be:

- A command: `bun test`
- A command prefix that ends in `*`: `bun test*`
- A tool and a file: `edit_file: src/index.ts`
- A tool name: `web_fetch`. A rule with only `bash` blocks all commands as a deny rule. As an allow rule, December ignores it.

Project rules are in `.december/settings.json`. Global rules are in `~/.december/config.json`. When you select **Always allow** in a permission prompt, December saves the exact command or file as a project rule.

In `/permissions`, press `a` to add a project rule, `g` to add a global rule, `d` to remove the selected rule, and `m` to switch between always-proceed and always-ask.

### `/hooks`

Shows the hooks that run, grouped by event. A hook is a shell command that December runs before a tool call, when you send a prompt, or when a turn ends. See [Hooks](/docs/hooks).

### `/github`

Shows the GitHub repository in the current folder and the status of the December GitHub App on it. With the app, you can comment `@trydecember <task>` on an issue or a pull request. See [GitHub App](/docs/github-app).

If you are not signed in with December, run `/login` to see the status.

Press `i` to open the install page of the app in your browser. Press `r` to check again.

### `/keybindings`

Opens `~/.december/keybindings.json`. If the file does not exist, December makes it with the default keys first.

```json
{
    "bindings": {
        "togglePlanMode": "ctrl+g",
        "newline": ["alt+enter", "shift+enter"]
    }
}
```

December applies the changes when you save the file. When you move an action to a new key, its old key stops working in the prompt. `/help` shows the keys that are in use. You cannot change `ctrl+c` and `esc`.

## Other commands

| Command               | What it does                                                       |
| :-------------------- | :----------------------------------------------------------------- |
| `/btw <question>`     | Ask a side question. The answer does not go into the conversation. |
| `/changelog`          | Open the December changelog in your browser.                       |
| `/codesearch <query>` | Search the code in your workspace.                                 |
| `/context`            | Show how much of the context window the session uses.              |
| `/copy`               | Copy the last response to the clipboard.                           |
| `/diff`               | Show the changes of this session. Press `s` to show all changes.   |
| `/exit`               | Exit the CLI.                                                      |
| `/feedback`           | Open the issue page to send feedback or report a bug.              |
| `/fork [title]`       | Start a new branch of the conversation from this point.            |
| `/help`               | Show commands, keyboard shortcuts, and CLI information.            |
| `/mcp`                | Show the running MCP servers and their tools. Restart or stop one. |
| `/new`                | Start a new conversation.                                          |
| `/open <file>`        | Open a file in the file viewer.                                    |
| `/rename [title]`     | Rename the session. With no title, December writes one for you.    |
| `/resume`             | Find and resume an earlier conversation.                           |
| `/rewind`             | Restore files and conversation to an earlier turn.                 |
| `/settings`           | Open the settings.                                                 |
| `/switch`             | Change the active provider and model.                              |
| `/tasks`              | Show background tasks.                                             |
| `/update`             | Update the CLI, then press Enter or run `/restart` to use it.      |
| `/usage`              | Show your token usage for this session and your usage history.     |
| `/voice`              | Speak a prompt with your microphone (uses Deepgram).               |

## Session titles

December gives each session a title, so you can find it again in `/resume`.

- When you send the first prompt, the session gets a title from that prompt.
- After the first response, December asks your model for a short title of 3 to 6 words. This uses a small number of tokens.
- To set your own title, run `/rename <title>`. December does not change a title that you set.
- To get a new title from the conversation so far, run `/rename` with no title.
- To rename an earlier session, run `/resume`, select the session, and press `r`.
- To resume a session by its title, run `december resume <title>`.

The title also shows in the window title of your terminal.
