## Available Slash Commands

December provides quick-action slash commands directly inside the prompt bar:

### `/login`

Opens the interactive authentication manager. Allows switching between:

- **December Cloud Account**: Unified billing and shared credits.
- **BYOK (Bring Your Own Key)**: Configure keys for OpenAI, Anthropic, Gemini, OpenRouter, and DeepSeek.

### `/model [model-name]`

Inspects or switches the active intelligence engine:

- `claude-fable-5-1`
- `gpt-5.6-sol`
- `gpt-6-astra`
- `gemini-3.8-flash`
- `deepseek-r1`

### `/clear`

Resets the conversation context while preserving file modifications. Use this when transitioning to an unrelated task to keep token context concise.

### `/docs [section]`

Opens the official documentation on `trydecember.com/docs` matching the requested section (e.g. `/docs cli`).

### `/effort [level]`

Inspects or configures the active model reasoning depth (`auto`, `off`, `low`, `medium`, `high`):

- **`/effort`**: Opens the interactive reasoning depth selector.
- **`/effort [level]`**: Directly sets the reasoning level (e.g. `/effort high`, `/effort off`).

### `/artifacts`

Opens the interactive session artifacts viewer to inspect, navigate, and approve implementation plans, architecture specs, and task walkthroughs stored under `~/.december/artifacts/<session-id>/`.

### `/skills`

Opens the interactive skills browser to inspect, search, and view documentation for all discovered skills across workspace, global, and plugin directories. Press `Enter` on any skill to read its `SKILL.md` in the code viewer.
