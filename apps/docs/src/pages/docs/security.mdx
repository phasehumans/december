## Security & Privacy Model

Keeping your source code and API keys private is our top priority:

### 1. Local Terminal Safety

- **Stays inside your project**: December only reads files within your project folder.
- **Safety checks**: December asks for confirmation before running dangerous commands like deleting folders or force-pushing git branches.
- **You are always in control**: You can press `Ctrl + C` or type `/undo` at any point to cancel or revert changes.

### 2. Cloud Sandbox Isolation

- **Private containers**: Every cloud workspace runs in its own isolated Linux sandbox.
- **Zero shared state**: Your files and servers are never shared with other users.
- **Automatic cleanup**: Inactive cloud sandboxes are cleanly shut down and wiped.

### 3. API Key & Data Encryption

- **Direct communication**: When you use your own API keys (BYOK), requests go straight to the model provider (Anthropic, OpenAI, Google) without December storing your code.
- **Local storage**: Keys are saved on your own computer in `~/.december/config.json` with restricted user permissions.
