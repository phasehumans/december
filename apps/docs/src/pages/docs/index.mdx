December is a coding agent. It reads your code, writes changes, and runs commands for you.

You can use December in two places:

- In your terminal, with the CLI.
- In December Cloud at [app.trydecember.com](https://app.trydecember.com), where your project runs in a sandbox with a live preview.

December works with any model. Link a plan you already pay for, sign in with December, or use your own keys.

## Install

```bash
npm install -g @trydecember/cli
```

Then run `december` in your project folder. For the full setup, read the [Quickstart](/docs/quickstart).

If you find a bug or want a feature, [open an issue](https://github.com/phasehumans/december/issues) or email [team@trydecember.com](mailto:team@trydecember.com).
