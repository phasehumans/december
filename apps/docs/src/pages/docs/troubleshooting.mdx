This page helps you fix common problems when you use December.

## 1. December cannot find your API key (401 Unauthorized)

The CLI uses the keys that you save with `/login` or `december key`. The CLI does not read `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` from your shell to sign in.

1. Type `/login` in a session.
2. Select Use your own API Key (BYOK). Then select your provider and paste the key.
3. Or save the key from your terminal with one command:

```bash
december key anthropic sk-ant-...
```

4. If the problem continues, run `december doctor` to check your setup:

```bash
december doctor
```

## 2. A port is already in use (for example, port 3000)

If you see `EADDRINUSE: address already in use :::3000`, another process uses the port. Stop that process.

On macOS and Linux:

```bash
# Find the process on port 3000
lsof -i :3000

# Stop the process
kill -9 <PID>
```

On Windows (PowerShell):

```powershell
# Find and stop the process on port 3000
Get-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess | Stop-Process
```

## 3. Rate limits (429 Too Many Requests)

The model provider sets the rate limit, not December.

1. Type `/model` to select a different model, or `/switch` to select a different provider.
2. Check the billing tier of your provider account. Free tiers often have lower limits.
3. Give December specific file names in your prompt. For example: "fix the type error in `src/auth.ts`". December then reads fewer files.

## 4. Undo changes that you do not want

December saves a snapshot of your files at each turn.

- Type `/rewind` and select a turn to revert the files and the conversation to that turn.
- From your terminal, run `december rewind list` to see the turns.

You can also use Git to discard all uncommitted changes:

```bash
git restore .
```

For more information, see [Git Checkpoints](/docs/checkpoints).

## 5. Stop a running task (Ctrl+C)

If December runs a command for too long, such as a slow build or a test that does not stop:

- Press Ctrl+C to stop the current turn. Your session stays open.
- If December is not working, Ctrl+C clears the input.
- If the input is empty, press Ctrl+C two times to exit December.

## 6. Get help and report bugs

- GitHub Issues: [open an issue](https://github.com/phasehumans/december/issues). Include the steps to reproduce the problem.
- Email: [team@trydecember.com](mailto:team@trydecember.com).
- Changelog: see [/docs/changelog](/docs/changelog) for the latest fixes.
- In a session, type `/feedback` to send feedback or report a bug.
