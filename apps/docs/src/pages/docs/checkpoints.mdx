This page tells you how December saves your files at each turn and how you undo a change.

## Automatic Restore Points

When you send a prompt, December saves a snapshot of your project files before it starts work. Each snapshot belongs to one turn.

- Separate history: December keeps snapshots in a separate git repository in `.december/snapshots`. Your own git history and branches do not change.
- Ignored files stay out: Snapshots skip the files in your `.gitignore`. They also skip `node_modules`, `dist`, `.git`, and `.december`.
- Review changes: Type `/diff` to see the git diff of your workspace.
- Go back to a turn: Type `/rewind` and select a turn. December restores the files and the conversation to that point. The most recent turn is at the top of the list.

## Rewind from the terminal

You can also restore a turn outside a session. To list the saved turns, run:

```bash
december rewind list
```

To restore a turn, add its number. With no number, December restores the latest snapshot.

```bash
december rewind 3
```
