This page helps you see and test your app while December builds it in December Cloud.

## Live Browser Previews

In December Cloud, your project runs in a sandbox. The sandbox is a cloud machine, so the code does not run on your computer.

- Automatic preview: When your app starts a dev server, December finds the port and shows a preview of the app. December checks common dev server ports first, for example 5173 (Vite) and 3000 (Next.js).
- Database ports stay hidden: December does not show a preview for database ports such as 5432 (PostgreSQL) or 6379 (Redis).
- Logs: The preview shows console logs, so you can find errors while you test.

## Sandbox limits

Each December Cloud session runs in its own sandbox. You can have 3 active sandboxes at a time. If you start a fourth, December pauses the sandbox you used least recently.
