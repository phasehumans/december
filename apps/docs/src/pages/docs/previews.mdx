## Live Browser Previews

When you work in December Cloud, your code runs inside a secure Linux sandbox with instant web previews:

- **Automatic Port Forwarding**: Whenever your app starts a dev server (like Next.js on port 3000 or Vite on 5173), December automatically opens a live preview.
- **Isolated Linux Environment**: Your code builds and runs inside its own safe container without risking your host machine.
- **Console & Diagnostics**: View build outputs, server logs, and runtime errors in real time right next to your code.
