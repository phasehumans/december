This page helps you see and test your app while December builds it in December Cloud.

## Live Browser Previews

In December Cloud, your project runs in a sandbox. The sandbox is a cloud machine, so the code does not run on your computer.

- Automatic preview: When your app starts a dev server, December finds the port and shows a preview of the app. December checks common dev server ports first, for example 5173 (Vite) and 3000 (Next.js).
- Database ports stay hidden: December does not show a preview for database ports such as 5432 (PostgreSQL) or 6379 (Redis).
- Logs: The preview shows console logs, so you can find errors while you test.

## Sandbox limits

Each December Cloud session runs in its own sandbox. You can have 10 running sandboxes at a time. If you start one more, December pauses the sandbox you used least recently.

## Sandbox settings

Open **Settings > Sandbox** to see and control your sandboxes.

- Running now: The list shows each sandbox that runs, with its repository, its run time, and its cost so far. Select **Stop** to pause a sandbox.
- Stop when idle for: December pauses a sandbox when nothing happens in it for this time. Pick 10 minutes, 30 minutes, or 1 hour. The default is 10 minutes.
- Archive sessions after: December archives a session when nothing changes in it for this time. Pick 7 days, 30 days, or Never. Pinned sessions and sessions with a running sandbox stay.

A paused sandbox starts again when you send a message in its session.
