## Overview

The December CLI (`@trydecember/cli`) runs directly inside your local project. It reads your files, runs tests, fixes bugs, and commits clean git diffs:

```bash
# Start December in the current working directory
december

# Start with a specific instruction prompt
december "Fix failing unit tests in packages/server"

# Start with a specific model
december --model claude-3-7-sonnet
```

## Global CLI Commands

| Command                        | Description                                            |
| :----------------------------- | :----------------------------------------------------- |
| `december`                     | Start the interactive conversational session           |
| `december login`               | Authenticate with December Cloud or configure API keys |
| `december skill list`          | List discovered built-in, global, and workspace skills |
| `december skill add <repo>`    | Install skills from GitHub (e.g. `phasehumans/skills`) |
| `december skill info <name>`   | View description, parameters, and playbook details     |
| `december skill remove <name>` | Uninstall a skill from workspace or global directory   |
| `december docs [section]`      | Open technical documentation in your default browser   |
| `december changelog`           | Open changelog in your default browser                 |
| `december update`              | Check for and install the latest CLI release           |
| `december version`             | Print current CLI version information                  |

## In-Session Keyboard Shortcuts

- `Ctrl + C`: Interrupt current agent generation or abort running process
- `Ctrl + L`: Clear terminal buffer while preserving session history
- `Up / Down`: Navigate prompt input history
- `Esc`: Cancel active modal or menu selection

## In-Session Slash Commands

While in an active December session, use slash commands to steer execution:

- `/login`: Manage provider API keys or switch active authentication mode
- `/clear`: Clear active chat transcript and reset agent memory
- `/memory`: View and manage learned workspace memory (.december/memory.md) and project rules (AGENTS.md)
- `/model`: Switch between supported LLMs (Claude Fable, GPT 5 series / Astra, Gemini 3.8, DeepSeek)
- `/plan`: Activate the implementation planning skill
- `/grill-me`: Launch a pre-implementation alignment interview
- `/code-review`: Trigger a comprehensive code quality and smell review
- `/<skill-name>`: Any installed community or workspace skill becomes an instant slash command
- `/docs`: Open documentation directly in your browser
- `/changelog`: Open changelog directly in your browser
- `/exit` or `/quit`: Terminate the terminal session
