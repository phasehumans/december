This page lists the commands, flags, and keyboard shortcuts of the December CLI.

## Overview

The CLI (`@trydecember/cli`) runs in your project folder. It reads your files, edits code, and runs commands such as your tests.

```bash
# Start an interactive session in the current folder
december

# Run one prompt, print the result, and exit
december --print "Fix the failing unit tests in packages/server"

# Start a session with a specific model
december --model claude-opus-5
```

If you pass a prompt, December runs it without the interactive session. By default it streams JSON events (NDJSON). Add `--print` to get plain text.

## Global CLI Commands

| Command                          | What it does                                                           |
| :------------------------------- | :--------------------------------------------------------------------- |
| `december`                       | Start an interactive session.                                          |
| `december "<prompt>"`            | Run one prompt without the interactive session.                        |
| `december ask "<question>"`      | Ask a question about the code. December only reads files.              |
| `december resume [title]`        | Resume the last session, or the session with this title or ID.         |
| `december login [provider]`      | Sign in with December. Add a provider name to link a plan.             |
| `december link <provider>`       | Link a plan: `claude`, `chatgpt`, `copilot`, `gemini`, or `amazon-q`.  |
| `december key <provider> [key]`  | Save your own API key for a provider.                                  |
| `december logout [provider]`     | Remove saved sign-in data and keys.                                    |
| `december switch [provider]`     | Change the active provider.                                            |
| `december auth [status\|import]` | Show sign-in status, or import plans from other CLIs on this computer. |
| `december plugin list`           | List the installed plugins, skills, and MCP servers.                   |
| `december plugin discover`       | List the plugins in your marketplaces.                                 |
| `december plugin install <src>`  | Install a plugin by name, folder, git url, or `owner/repo`.            |
| `december plugin info <name>`    | Show the details of a plugin or skill.                                 |
| `december plugin disable <name>` | Turn off a plugin or skill. Use `enable` to turn it on.                |
| `december plugin uninstall <n>`  | Uninstall a plugin.                                                    |
| `december plugin marketplace`    | List marketplaces. Add `add`, `update`, or `remove` and a name.        |
| `december mcp [list]`            | Show the configured MCP servers.                                       |
| `december rewind [turn\|list]`   | List saved turns, or restore your files to a turn.                     |
| `december doctor [--fix]`        | Check the install and setup. Add `--fix` to repair `PATH` problems.    |
| `december docs [section]`        | Open the documentation in your browser.                                |
| `december changelog`             | Open the changelog in your browser.                                    |
| `december update [--check]`      | Install the latest release. `--check` only shows the version.          |

## Flags

| Flag                    | What it does                                                |
| :---------------------- | :---------------------------------------------------------- |
| `-h`, `--help`          | Show the help and exit.                                     |
| `-v`, `--version`       | Show the CLI version and exit.                              |
| `-r`, `--resume`        | Resume the last session.                                    |
| `-m`, `--model <model>` | Use this model.                                             |
| `-y`, `--yes`           | Approve tool calls without asking.                          |
| `--print`               | Print plain text for a one-prompt run. Approves tool calls. |
| `--json`                | Print JSON events for a one-prompt run.                     |
| `--session-id <id>`     | Use this session ID.                                        |
| `--scope <dir>`         | Keep December inside one folder, such as a package.         |
| `--cwd <dir>`           | Set the working folder.                                     |

## In-Session Keyboard Shortcuts

- `Ctrl + C`: Stop December or exit the CLI.
- `Esc`: Close a menu or clear the input.
- `Ctrl + P` / `Ctrl + N`: Go to the previous or next prompt in your history.
- `Up` / `Down`: Scroll the chat when the prompt is empty.
- `Ctrl + L`: Open or close the slash command menu.
- `Ctrl + O`: Show or hide tool output.
- `Ctrl + T`: Show or hide background tasks.
- `Ctrl + B`: Move the running shell command to the background. In tmux, press `Ctrl + B` two times.
- `@` and a file name: Add a file to the prompt.
- `!` and a command: Run a shell command directly, for example `!git status`.

Type `/help` in a session to see the full list.

## In-Session Slash Commands

In a session, type `/` to see the slash commands. These are the most common:

- `/login`: Link a plan, sign in with December, or add your own keys.
- `/model`: Pick a model from your connected provider.
- `/clear`: Clear the conversation history.
- `/memory`: Show your project rules (`AGENTS.md`, or `CLAUDE.md` if there is no `AGENTS.md`).
- `/learn [lesson]`: Save a lesson from the conversation to `AGENTS.md` or a skill.
- `/plan <goal>`: Make a plan that you approve before December changes code.
- `/<skill-name>`: Run an installed skill.
- `/docs`: Open the documentation in your browser.
- `/changelog`: Open the changelog in your browser.
- `/exit`: Exit the CLI.

See [Slash Commands](/docs/slash-commands) for the full list.
