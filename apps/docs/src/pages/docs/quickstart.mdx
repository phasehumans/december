This page helps you start your first December session. You can use December in your terminal or in December Cloud.

## 1. Use December in your terminal

### Install the CLI

1. Install the CLI with npm:

```bash
npm install -g @trydecember/cli
```

2. Go to your project folder and start December:

```bash
cd my-project
december
```

### Connect a model

December needs a model to work. Run `/login` and pick one of these options:

- Link a plan: Use a plan you already pay for. December supports Claude, ChatGPT, GitHub Copilot, and Gemini plans.
- Sign in with December: Use your December Cloud account and its monthly credits.
- Use your own keys: Add API keys for OpenAI, Anthropic, Gemini, OpenRouter, or DeepSeek.

After you connect a model, type what you want December to do. For example: "fix the failing tests".

## 2. Use December Cloud

December Cloud runs your project in a sandbox. You do not need to install anything.

1. Go to [app.trydecember.com](https://app.trydecember.com) and sign in.
2. Describe what you want to build, or connect a GitHub repository.
3. December starts a sandbox, writes the code, and starts your app.
4. Use the preview to test your app in the browser. The preview also shows console logs.
