When building autonomous agents, developers spend weeks tuning prompts and temperatures. Yet in production, the most frequent failure point is tool invocation.

An analysis of agent traces by Composio ([_How to build great tools for AI agents_](https://composio.dev/blog/how-to-build-tools-for-ai-agents-a-field-guide)) demonstrates that tool failures are primarily API design failures. Below are the key rules for designing high-reliability tools for agents.

## 1. Predictable Naming Conventions

LLMs rely on semantic pattern recognition. Mixed casings and ambiguous verbs cause models to second-guess tool choices:

- **Avoid**: `fetch_user_profile`, `getProjectDetails`, `User_Settings_Update`
- **Use**: `get_user_profile`, `get_project_details`, `update_user_settings`

Standardizing on lowercase `snake_case` with a clear `<verb>_<noun>` structure establishes a consistent invocation model.

## 2. Atomic Tool Scope

Broad "Swiss Army knife" tools create parameter ambiguity:

- **Avoid**: A monolithic `manage_files(action="read"|"edit"|"delete", path, ...)` tool.
- **Use**: Dedicated primitives like `view_file(path, start_line, end_line)`, `write_to_file(path, content)`, and `replace_file_content(path, target, replacement)`.

Single-concern tools reduce the parameter space and prevent conflicting arguments.

## 3. Constraint-First Descriptions

Tool descriptions should function as strict contracts rather than marketing copy:

1. **Action**: Exactly what the tool modifies or reads.
2. **Trigger**: When the agent should choose this tool over alternatives.
3. **Constraints**: Immediate preconditions, line limits, and formatting rules.

Placing hard constraints at the start of the description gives them higher attention weight during schema evaluation.

## 4. Strict Typing and Enums

- **Use finite enums**: Avoid open strings when valid options are known (`"mode": ["fast", "precise"]`).
- **Cap top-level arguments**: Tools with more than 4-5 top-level arguments have higher failure rates. Group optional settings into nested objects.
- **Specify formats**: Use explicit schema formats like `"format": "uri"` or line-indexed integers.

## 5. Actionable Error Returns

Generic error codes leave agents blind, often triggering infinite retry loops:

- **Avoid**: `{"error": "500 Internal Server Error"}`
- **Use**: `{"success": false, "error": "Target content not found in lines 40-55. Found partial match on line 48. Re-read the file before retrying."}`

Returning corrective diagnostics allows the agent to self-heal deterministically.

## How December Implements Tooling

December structures its agent tool harness on these principles:

- **Targeted edits**: File modifications require exact `StartLine`, `EndLine`, and matching `TargetContent`.
- **Isolated execution**: Shell commands run inside MicroVM sandboxes with exit codes and raw stderr returned directly to the reasoning loop.
- **Immediate lint feedback**: Syntax and compiler errors are fed back on each step for zero-overhead correction.
