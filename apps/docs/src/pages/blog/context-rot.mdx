Modern LLMs advertise context windows scaling from 128k to 1M+ tokens. The common assumption is that models process this space uniformly - that a rule or interface placed at token 100k is recalled as reliably as one at token 100.

Empirical research by Chroma ([_Context Rot_](https://www.trychroma.com/research/context-rot)) shows this assumption fails in practice. As input length expands, retrieval accuracy degrades sharply under semantic ambiguity, a phenomenon known as **Context Rot**.

## The Uniformity Myth

In theory, self-attention connects all tokens pairwise. In reality, attention weights dilute across massive sequences. When an agent dumps whole directories into a prompt, probability mass spreads across irrelevant tokens, leading to:

1. **Instruction drift**: Early system constraints are deprioritized.
2. **Attribution blending**: Disparate code snippets merge into invalid implementations.
3. **Hallucination**: The model invents missing details when context density exceeds retrieval limits.

## Semantic Degradation vs. Standard NIAH

Standard Needle in a Haystack (NIAH) tests measure **exact lexical overlap** - searching for a specific string inside unrelated text. This behaves like an optimized grep search and yields deceptively high scores.

When tested against **non-lexical semantic relationships** (where concepts are referenced indirectly without identical keywords), retrieval accuracy drops rapidly as context expands:

```
Retrieval Accuracy
 100% |===============\
      |                \   Lexical Matching (Standard NIAH)
  50% |         \       \---------------------------
      |          \--- Semantic Non-Lexical Matching
   0% +---------------------------------------------
      1K        16K        64K       128K      256K+
                      Input Tokens
```

## Distractors in Codebases

The Chroma study highlights the critical distinction between **orthogonal noise** and **distractors**:

- **Noise**: Completely unrelated text (e.g. documentation mixed with history essays). Models ignore this relatively well.
- **Distractors**: Topically related content that looks like the target but is incorrect.

Codebases are filled with distractors: overloaded signatures (`getUser`, `getUserById`), outdated legacy modules, and test mock fixtures. When an agent floods context with 50 unpruned files, the model frequently selects the wrong signature or imports deprecated utilities.

## How December Mitigates Context Rot

Rather than relying on oversized prompt dumps, December uses targeted context pruning:

- **Localized AST extraction**: Only referenced symbols and type interfaces are loaded into context, not entire files.
- **Pruned agent reasoning loop**: Diagnostic terminal output and intermediate planning traces are discarded once verified.
- **Deterministic checkpoints**: Verification uses compiler diagnostics and test exits in isolated sandboxes rather than prompt memory.
