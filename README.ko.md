December는 더 나은 코딩 에이전트입니다. 코드를 읽고, 변경 사항을 작성하고, 명령을 실행합니다. 터미널에서도, 클라우드([trydecember.com](https://trydecember.com))에서도 사용할 수 있습니다.

<p align="center">
  <img src="https://github.com/user-attachments/assets/8e15b973-eddc-4bcb-96a0-26d37c35c718" alt="December" width="100%"/>
</p>

- 어떤 모델이든 사용할 수 있습니다. 이미 결제 중인 플랜(Claude, ChatGPT, GitHub Copilot, Gemini)을 연결하거나, December에 로그인하거나, 40개 이상 제공업체의 API 키를 사용하세요.
- 클라우드에서 실행할 수 있습니다. December Cloud는 프로젝트를 샌드박스에서 실행하고 앱의 실시간 미리보기를 보여 줍니다.
- 큰 작업을 나눌 수 있습니다. December는 하위 작업을 여러 보조 에이전트에게 동시에 맡길 수 있습니다.
- 도구를 추가할 수 있습니다. 스킬로 작업 방식을 알려 주고, MCP로 도구를 연결하세요.

### 시작하기

1. CLI를 설치합니다:

```bash
npm install -g @trydecember/cli
```

2. 프로젝트 디렉터리로 이동한 후 `december`를 실행합니다.

3. `/login`을 입력해 모델을 연결한 다음, December에게 할 일을 알려 주세요.

자세한 내용은 [문서](https://trydecember.com/docs)를 참고하세요.
