December는 (so much) better 코딩 에이전트입니다. 코드 작성, 버그 수정, 명령어 실행을 통해 개발을 더 빠르게 진행할 수 있도록 돕습니다. 터미널에서 직접 사용하거나 원하는 IDE와 함께 사용할 수 있습니다.

**웹에서도 사용 가능: <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

- **코드 작성 및 명령어 실행:** 기능 개발, 버그 수정, 테스트 실행을 요청해 보세요. 에이전트가 알아서 수행합니다.
- **클라우드 샌드박스:** 원격 실행 환경 및 실시간 미리보기를 빠르게 시작할 수 있습니다.
- **원하는 AI 모델 연결:** OpenAI, Anthropic, Gemini 및 100개 이상의 다른 모델 API 키를 사용하거나, December에 로그인하여 December 크레딧을 사용할 수 있습니다.
- **영구 워크스페이스 메모리:** 컨텍스트 저하 없이 여러 세션에 걸쳐 프로젝트 규칙과 팀 표준을 학습합니다.
- **자율 멀티 에이전트 팀:** 백그라운드 서브에이전트를 병렬로 실행하여 문서 조사, 디버깅, 테스트 실행을 분담합니다.
- **확장 가능한 Skills 및 MCP:** 커스텀 스킬을 연결하고 MCP를 통해 외부 개발 도구 또는 API와 연동합니다.

### 시작하기

1. December 설치:

Bash (macOS & Linux):

```bash
curl -fsSL https://trydecember.com/install.sh | bash
```

PowerShell (Windows):

```powershell
irm https://trydecember.com/install.ps1 | iex
```

NPM:

```bash
npm install -g @trydecember/cli
```

2. 프로젝트 디렉터리로 이동한 후 `december`를 실행합니다.
