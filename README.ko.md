December는 터미널과 클라우드를 위한 (so much) better 코딩 에이전트입니다. 사용자의 코드베이스를 이해하고 코드 작성, 버그 수정, 명령어 실행을 통해 개발을 더 빠르게 진행할 수 있도록 돕습니다. 터미널에서 직접 사용하거나 원하는 IDE와 함께 사용할 수 있습니다.

**웹에서도 사용 가능: <a href="https://trydecember.com" target="_blank">trydecember.com</a>**

  <img src="https://github.com/user-attachments/assets/585e6ff5-0403-45f5-89c3-c2d3d168962c" alt="December" width="80%"/>

- **코드 작성 및 명령어 실행:** 기능 개발, 버그 수정, 테스트 실행을 요청해 보세요. 에이전트가 알아서 수행합니다.
- **클라우드 핸드오프:** _/handoff_ 명령어를 사용하여 **<a href="https://trydecember.com" target="_blank">trydecember.com</a>** 에서 세션을 이어가세요.
- **원하는 AI 모델 연결:** OpenAI, Anthropic, Gemini 및 150개 이상의 다른 모델 API 키를 사용하거나, December에 로그인하여 December 크레딧을 사용할 수 있습니다.

### 시작하기

1. December 설치:

```bash
npm install -g @trydecember/cli
```

2. 프로젝트 디렉터리로 이동한 후 `december`를 실행합니다.
